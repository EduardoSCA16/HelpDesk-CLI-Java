# 🛠️ HelpDesk CLI — Sistema de Chamados de TI

Um sistema de **gerenciamento de chamados de suporte técnico** desenvolvido em Java e executado via terminal (CLI).

O projeto tem como objetivo simular o funcionamento básico de um setor de suporte de TI, permitindo o registro e gerenciamento de solicitações de atendimento.

> 🚧 **Projeto em desenvolvimento**
>
> Este projeto ainda está em fase inicial de planejamento e será desenvolvido gradualmente conforme novos conhecimentos forem adquiridos durante os estudos de Java.

## 🎯 Objetivo

Este projeto foi desenvolvido com o objetivo de praticar e consolidar conhecimentos em **Java e Programação Orientada a Objetos**, aplicando os conceitos estudados em uma aplicação baseada em um problema próximo de um cenário real.

## 💡 Sobre o projeto

A aplicação terá como foco o gerenciamento de chamados de TI, envolvendo informações como:

* Usuários e solicitantes;
* Técnicos responsáveis;
* Descrição dos problemas;
* Prioridade dos chamados;
* Status dos atendimentos;
* Acompanhamento e encerramento dos chamados.

## 🧠 Conceitos que serão praticados

Durante o desenvolvimento, serão aplicados conceitos como:

* Programação Orientada a Objetos;
* Classes e objetos;
* Encapsulamento;
* Herança e polimorfismo;
* Interfaces;
* Enums;
* Collections;
* Tratamento de exceções;
* Organização de código;
* Consumo de APIs.

## 🛠️ Tecnologias

* Java
* JDK 25
* Git e GitHub
* Gson
